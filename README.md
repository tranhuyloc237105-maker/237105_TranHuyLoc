# Hệ Thống Quản Lý Nhân Sự

- **Họ và tên:** Trần Huy Lộc
- **MSSV:** 237105
- **Lớp:** DH23TIN10

## Mô tả hệ thống
Hệ thống quản lý nhân sự cho phép hiển thị danh sách nhân viên, xem thông tin chi tiết, thêm mới, cập nhật, tìm kiếm và xóa hồ sơ nhân viên. Dữ liệu được lưu trữ trên MongoDB Atlas và giao tiếp thông qua REST API.

## Công nghệ sử dụng
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Đóng gói & Lưu trữ:** Docker, Docker Hub
- **Triển khai:** Render
